# 365 Calendar — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Objectif :** une PWA de défi photo personnel — un thème par jour, une photo qui s'y lie avec une note optionnelle, une galerie pour revoir les vieux jours. Progression sans pression : le thème suivant n'est débloqué que quand la photo du thème en cours est validée. Données 100 % locales (IndexedDB), jamais envoyées.

**Architecture :** SPA React sans routeur, clone structurel de mymap. Modules logiques purs et testables (`themes`, `photoUtils`, `db`, `exportImport`) + composants UI pilotés par props (`TodayView`, `GalleryView`, `DayDetail`, `Toolbar`) assemblés dans un `App.tsx` fin. Deux onglets (Aujourd'hui / Galerie) + vue détail en overlay, gérés par l'état React.

**Stack :** Vite · React 19 · TypeScript strict · idb (IndexedDB) · lucide-react (icônes) · vite-plugin-pwa · Vitest + Testing Library (jsdom, fake-indexeddb) · ESLint.

**Spec :** `docs/superpowers/specs/2026-10-16-365-calendar-design.md`

**Conventions :** interface et tests en français ; identifiants de code en anglais ; chaînes UI entre guillemets doubles ; commits fréquents ; TDD pour les modules et composants ; ne jamais commiter `node_modules/`, `dist/`, `dev-dist/`.

- [ ] **Step 12: Écrire `scripts/generate-icons.mjs`** (icônes PWA : appareil photo orange, écriture PNG sans dépendance)

```js
import { deflateSync } from 'node:zlib';
import { mkdirSync, writeFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';

const outDir = join(dirname(fileURLToPath(import.meta.url)), '..', 'public', 'icons');

const CRC_TABLE = (() => {
  const table = new Int32Array(256);
  for (let n = 0; n < 256; n++) {
    let c = n;
    for (let k = 0; k < 8; k++) {
      c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
    }
    table[n] = c;
  }
  return table;
})();

function crc32(buf) {
  let c = -1;
  for (let i = 0; i < buf.length; i++) {
    c = CRC_TABLE[(c ^ buf[i]) & 0xff] ^ (c >>> 8);
  }
  return (c ^ -1) >>> 0;
}

function chunk(type, data) {
  const len = Buffer.alloc(4);
  len.writeUInt32BE(data.length);
  const body = Buffer.concat([Buffer.from(type, 'ascii'), data]);
  const crc = Buffer.alloc(4);
  crc.writeUInt32BE(crc32(body));
  return Buffer.concat([len, body, crc]);
}

function makePng(size) {
  // Appareil photo : barre blanche (flash) + anneau blanc (objectif) sur fond orange
  const cx = size / 2;
  const cy = size * 0.56;
  const ringR = size * 0.24;
  const ringW = size * 0.075;
  const barTop = size * 0.24;
  const barBottom = size * 0.33;
  const barHalf = size * 0.17;
  const bg = [217, 95, 43];
  const fg = [255, 251, 245];
  const rowLen = size * 3;
  const raw = Buffer.alloc((rowLen + 1) * size);
  for (let y = 0; y < size; y++) {
    const rowStart = y * (rowLen + 1);
    raw[rowStart] = 0;
    for (let x = 0; x < size; x++) {
      const dist = Math.sqrt((x - cx) ** 2 + (y - cy) ** 2);
      const inRing = Math.abs(dist - ringR) <= ringW / 2;
      const inBar = y >= barTop && y <= barBottom && Math.abs(x - cx) <= barHalf;
      const color = inRing || inBar ? fg : bg;
      const offset = rowStart + 1 + x * 3;
      raw[offset] = color[0];
      raw[offset + 1] = color[1];
      raw[offset + 2] = color[2];
    }
  }
  const ihdr = Buffer.alloc(13);
  ihdr.writeUInt32BE(size, 0);
  ihdr.writeUInt32BE(size, 4);
  ihdr[8] = 8;
  ihdr[9] = 2;
  return Buffer.concat([
    Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
    chunk('IHDR', ihdr),
    chunk('IDAT', deflateSync(raw, { level: 9 })),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}

mkdirSync(outDir, { recursive: true });
for (const size of [192, 512]) {
  writeFileSync(join(outDir, `icon-${size}.png`), makePng(size));
  writeFileSync(join(outDir, `icon-${size}-maskable.png`), makePng(size));
  console.log(`icon-${size}.png et icon-${size}-maskable.png générés`);
}
```

export class ThemesError extends Error {}

export function validateThemes(value: unknown): string[] {
  if (!Array.isArray(value) || value.length === 0) {
    throw new ThemesError("themes.json doit contenir un tableau d'au moins 1 thème.");
  }
  return value.map((theme, index) => {
    if (typeof theme !== 'string' || theme.trim().length === 0) {
      throw new ThemesError(`le thème #${index + 1} doit être une chaîne non vide.`);
    }
    return theme.trim();
  });
}

export async function loadThemes(): Promise<string[]> {
  let response: Response;
  try {
    response = (await fetch('themes.json')) as Response;
  } catch {
    throw new ThemesError('impossible de charger themes.json (réseau).');
  }
  if (!response.ok) {
    throw new ThemesError(`themes.json introuvable (HTTP ${String(response.status)}).`);
  }
  let parsed: unknown;
  try {
    parsed = await response.json();
  } catch {
    throw new ThemesError("themes.json n'est pas un JSON valide.");
  }
  return validateThemes(parsed);
}

export function isChallengeComplete(completedDays: number, themeCount: number): boolean {
  return completedDays >= themeCount;
}
```

export const MAX_PHOTO_EDGE = 1600;
export const JPEG_QUALITY = 0.85;

export function computeTargetDimensions(
  width: number,
  height: number,
  maxEdge: number = MAX_PHOTO_EDGE,
): { width: number; height: number } {
  if (width <= maxEdge && height <= maxEdge) {
    return { width, height };
  }
  const ratio = width >= height ? maxEdge / width : maxEdge / height;
  return {
    width: Math.max(1, Math.round(width * ratio)),
    height: Math.max(1, Math.round(height * ratio)),
  };
}

export async function compressPhoto(file: Blob): Promise<Blob> {
  const bitmap = await createImageBitmap(file);
  try {
    const { width, height } = computeTargetDimensions(bitmap.width, bitmap.height);
    const canvas = document.createElement('canvas');
    canvas.width = width;
    canvas.height = height;
    const ctx = canvas.getContext('2d');
    if (!ctx) {
      throw new Error('Canvas unavailable');
    }
    ctx.drawImage(bitmap, 0, 0, width, height);
    return await new Promise<Blob>((resolve, reject) => {
      canvas.toBlob(
        (blob) => (blob ? resolve(blob) : reject(new Error('Photo compression failed'))),
        'image/jpeg',
        JPEG_QUALITY,
      );
    });
  } finally {
    bitmap.close();
  }
}
```

import { openDB, type DBSchema, type IDBPDatabase } from 'idb';
import type { DayEntry } from './types';

interface CalendarDB extends DBSchema {
  days: { key: number; value: DayEntry };
}

let dbPromise: Promise<IDBPDatabase<CalendarDB>> | null = null;

function getDB(): Promise<IDBPDatabase<CalendarDB>> {
  if (!dbPromise) {
    dbPromise = openDB<CalendarDB>('calendar365', 1, {
      upgrade(db) {
        if (!db.objectStoreNames.contains('days')) {
          db.createObjectStore('days', { keyPath: 'dayNumber' });
        }
      },
    });
    dbPromise.catch(() => {
      dbPromise = null;
    });
  }
  return dbPromise;
}

export async function listDays(): Promise<DayEntry[]> {
  const db = await getDB();
  const days = await db.getAll('days');
  return days.sort((a, b) => b.dayNumber - a.dayNumber);
}

export async function saveDay(entry: DayEntry): Promise<void> {
  const db = await getDB();
  await db.put('days', entry);
}

export async function replaceAllDays(entries: DayEntry[]): Promise<void> {
  const db = await getDB();
  const tx = db.transaction('days', 'readwrite');
  try {
    await tx.store.clear();
    for (const entry of entries) {
      await tx.store.put(entry);
    }
  } catch (err) {
    tx.done.catch(() => {
      // transaction abandonnée : le rejet de done est attendu
    });
    try {
      tx.abort();
    } catch {
      // la transaction était déjà terminée
    }
    throw err;
  }
  await tx.done;
}

export function nextDayNumber(entries: Pick<DayEntry, 'dayNumber'>[]): number {
  return entries.reduce((max, entry) => Math.max(max, entry.dayNumber), 0) + 1;
}

import type { DayEntry } from './types';

export const EXPORT_VERSION = 1;

export class ImportError extends Error {}

interface SerializedPhoto {
  id: string;
  data: string;
}

interface SerializedDay {
  dayNumber: number;
  theme: string;
  photo: SerializedPhoto;
  note?: string;
  takenAt: number;
  updatedAt: number;
}

interface ExportFile {
  version: number;
  exportedAt: number;
  days: SerializedDay[];
}

async function blobToBase64(blob: Blob): Promise<string> {
  const bytes = new Uint8Array(await blob.arrayBuffer());
  let binary = '';
  const chunkSize = 0x8000;
  for (let i = 0; i < bytes.length; i += chunkSize) {
    binary += String.fromCharCode(...bytes.subarray(i, i + chunkSize));
  }
  return btoa(binary);
}

function base64ToBlob(data: string): Blob {
  const binary = atob(data);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) {
    bytes[i] = binary.charCodeAt(i);
  }
  if (bytes.length < 2 || bytes[0] !== 0xff || bytes[1] !== 0xd8) {
    throw new Error('invalid photo data');
  }
  return new Blob([bytes], { type: 'image/jpeg' });
}

export async function exportDays(days: DayEntry[]): Promise<string> {
  const file: ExportFile = {
    version: EXPORT_VERSION,
    exportedAt: Date.now(),
    days: await Promise.all(
      days.map(async (day): Promise<SerializedDay> => ({
        dayNumber: day.dayNumber,
        theme: day.theme,
        photo: { id: day.photo.id, data: await blobToBase64(day.photo.blob) },
        note: day.note,
        takenAt: day.takenAt,
        updatedAt: day.updatedAt,
      })),
    ),
  };
  return JSON.stringify(file, null, 2);
}

export function parseImportFile(text: string): DayEntry[] {
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch {
    throw new ImportError("le fichier n'est pas un JSON valide.");
  }
  if (typeof parsed !== 'object' || parsed === null) {
    throw new ImportError('structure de fichier inattendue.');
  }
  const file = parsed as Partial<ExportFile>;
  if (file.version !== EXPORT_VERSION) {
    throw new ImportError(`version du fichier non supportée (${String(file.version)}).`);
  }
  if (!Array.isArray(file.days)) {
    throw new ImportError('liste des jours manquante.');
  }
  const seen = new Set<number>();
  return file.days.map((day, index) => parseDay(day, index, seen));
}

function parseDay(day: unknown, index: number, seen: Set<number>): DayEntry {
  const prefix = `jour #${index + 1}`;
  if (typeof day !== 'object' || day === null) {
    throw new ImportError(`${prefix} : données invalides.`);
  }
  const d = day as Partial<SerializedDay>;
  if (typeof d.dayNumber !== 'number' || !Number.isInteger(d.dayNumber) || d.dayNumber < 1) {
    throw new ImportError(`${prefix} : numéro de jour invalide.`);
  }
  if (seen.has(d.dayNumber)) {
    throw new ImportError(`${prefix} : numéro de jour dupliqué (${String(d.dayNumber)}).`);
  }
  seen.add(d.dayNumber);
  if (typeof d.theme !== 'string' || d.theme.trim().length === 0) {
    throw new ImportError(`${prefix} : thème manquant.`);
  }
  if (
    typeof d.photo !== 'object' ||
    d.photo === null ||
    typeof d.photo.id !== 'string' ||
    d.photo.id.length === 0 ||
    typeof d.photo.data !== 'string'
  ) {
    throw new ImportError(`${prefix} : photo invalide.`);
  }
  let blob: Blob;
  try {
    blob = base64ToBlob(d.photo.data);
  } catch {
    throw new ImportError(`${prefix} : photo illisible.`);
  }
  if (d.note !== undefined && typeof d.note !== 'string') {
    throw new ImportError(`${prefix} : note invalide.`);
  }
  if (typeof d.takenAt !== 'number' || typeof d.updatedAt !== 'number') {
    throw new ImportError(`${prefix} : dates invalides.`);
  }
  return {
    dayNumber: d.dayNumber,
    theme: d.theme,
    photo: { id: d.photo.id, blob },
    note: d.note,
    takenAt: d.takenAt,
    updatedAt: d.updatedAt,
  };
}

export function buildExportFileName(date: Date = new Date()): string {
  return `calendar365-export-${date.toISOString().slice(0, 10)}.json`;
}

import { useRef, useState } from 'react';
import { Camera, Check, PartyPopper, Pencil, RotateCcw } from 'lucide-react';
import { compressPhoto } from '../photoUtils';
import './TodayView.css';

export interface TodayViewProps {
  dayNumber: number;
  theme: string;
  completedDays: number;
  themeCount: number;
  challengeComplete: boolean;
  onSave: (photo: Blob, note: string | undefined) => Promise<void>;
  onEditLast: () => void;
}

interface Draft {
  blob: Blob;
  url: string;
}

interface SavedSummary {
  dayNumber: number;
  theme: string;
  url: string;
  note?: string;
}

export default function TodayView({
  dayNumber,
  theme,
  completedDays,
  themeCount,
  challengeComplete,
  onSave,
  onEditLast,
}: TodayViewProps) {
  const [draft, setDraft] = useState<Draft | null>(null);
  const [note, setNote] = useState('');
  const [compressing, setCompressing] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [saving, setSaving] = useState(false);
  const [saved, setSaved] = useState<SavedSummary | null>(null);
  const fileInputRef = useRef<HTMLInputElement>(null);

  async function handleFile(file: File) {
    setError(null);
    setCompressing(true);
    try {
      const blob = await compressPhoto(file);
      if (draft) URL.revokeObjectURL(draft.url);
      setDraft({ blob, url: URL.createObjectURL(blob) });
    } catch {
      setError("Impossible de lire cette photo. Essaie une autre image.");
    } finally {
      setCompressing(false);
    }
  }

  function handleRetake() {
    if (draft) URL.revokeObjectURL(draft.url);
    setDraft(null);
    setError(null);
  }

  async function handleValidate() {
    if (!draft || saving) return;
    const savedDayNumber = dayNumber;
    const savedTheme = theme;
    const savedNote = note.trim() || undefined;
    setSaving(true);
    try {
      await onSave(draft.blob, savedNote);
      setSaved({ dayNumber: savedDayNumber, theme: savedTheme, url: draft.url, note: savedNote });
      setDraft(null);
      setNote('');
    } catch {
      setError("Impossible d'enregistrer la photo. Réessaie.");
    } finally {
      setSaving(false);
    }
  }

  function handleContinue() {
    if (saved) URL.revokeObjectURL(saved.url);
    setSaved(null);
    setError(null);
  }

  if (challengeComplete && !saved) {
    return (
      <div className="today today--complete">
        <PartyPopper size={48} aria-hidden="true" />
        <h2>Défi terminé !</h2>
        <p>
          Les {themeCount} thèmes ont été photographiés. Retrouve toutes tes photos dans la galerie.
        </p>
      </div>
    );
  }

  if (saved) {
    return (
      <div className="today">
        <section className="today__card">
          <p className="today__saved-title">Jour {saved.dayNumber} validé !</p>
          <img className="today__photo" src={saved.url} alt={`Photo du thème « ${saved.theme} »`} />
          {saved.note && <p className="today__note">{saved.note}</p>}
          {challengeComplete ? (
            <p className="today__next">Défi terminé — bravo !</p>
          ) : (
            <p className="today__next">Prochain thème : « {theme} »</p>
          )}
          <div className="today__actions">
            <button type="button" className="btn" onClick={onEditLast}>
              <Pencil size={18} aria-hidden="true" /> Modifier
            </button>
            <button type="button" className="btn btn--primary" onClick={handleContinue}>
              Continuer
            </button>
          </div>
        </section>
      </div>
    );
  }

  return (
    <div className="today">
      <section className="today__card">
        <p className="today__day">
          Jour {dayNumber} <span className="today__progress">· {completedDays} / {themeCount}</span>
        </p>
        <h2 className="today__theme">{theme}</h2>
        {draft ? (
          <>
            <img className="today__photo" src={draft.url} alt="Aperçu de la photo" />
            <label className="field">
              Note (optionnel)
              <textarea
                className="field__input"
                rows={3}
                value={note}
                onChange={(e) => setNote(e.target.value)}
                placeholder="Un souvenir, un contexte…"
              />
            </label>
            {error && (
              <p className="today__error" role="alert">
                {error}
              </p>
            )}
            <div className="today__actions">
              <button type="button" className="btn" onClick={handleRetake} disabled={saving}>
                <RotateCcw size={18} aria-hidden="true" /> Reprendre
              </button>
              <button
                type="button"
                className="btn btn--primary"
                onClick={handleValidate}
                disabled={saving}
              >
                <Check size={18} aria-hidden="true" /> {saving ? 'Validation…' : 'Valider'}
              </button>
            </div>
          </>
        ) : (
          <>
            {error && (
              <p className="today__error" role="alert">
                {error}
              </p>
            )}
            <button
              type="button"
              className="btn btn--primary btn--big"
              onClick={() => fileInputRef.current?.click()}
              disabled={compressing}
            >
              <Camera size={22} aria-hidden="true" />
              {compressing ? 'Préparation…' : 'Prendre la photo'}
            </button>
          </>
        )}
        <input
          ref={fileInputRef}
          type="file"
          accept="image/*"
          capture="environment"
          className="visually-hidden"
          aria-hidden="true"
          tabIndex={-1}
          onChange={(e) => {
            const file = e.target.files?.[0];
            e.target.value = '';
            if (file) void handleFile(file);
          }}
        />
      </section>
    </div>
  );
}

import { useEffect, useState } from 'react';

export function useObjectUrl(blob: Blob | null): string | null {
  const [url, setUrl] = useState<string | null>(null);

  useEffect(() => {
    if (!blob) {
      setUrl(null);
      return;
    }
    const next = URL.createObjectURL(blob);
    setUrl(next);
    return () => URL.revokeObjectURL(next);
  }, [blob]);

  return url;
}

import { useRef, useState } from 'react';
import { ArrowLeft, Camera, Check, Pencil, X } from 'lucide-react';
import { compressPhoto } from '../photoUtils';
import { useObjectUrl } from '../hooks/useObjectUrl';
import type { DayEntry } from '../types';
import './DayDetail.css';

export interface DayDetailProps {
  entry: DayEntry;
  onClose: () => void;
  onSave: (entry: DayEntry) => Promise<void>;
}

export default function DayDetail({ entry, onClose, onSave }: DayDetailProps) {
  const [editing, setEditing] = useState(false);
  const [draftBlob, setDraftBlob] = useState<Blob | null>(null);
  const [note, setNote] = useState(entry.note ?? '');
  const [compressing, setCompressing] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const [saving, setSaving] = useState(false);
  const fileInputRef = useRef<HTMLInputElement>(null);
  const photoUrl = useObjectUrl(entry.photo.blob);
  const draftUrl = useObjectUrl(draftBlob);

  function startEditing() {
    setNote(entry.note ?? '');
    setDraftBlob(null);
    setError(null);
    setEditing(true);
  }

  function cancelEditing() {
    setDraftBlob(null);
    setError(null);
    setEditing(false);
  }

  async function handleFile(file: File) {
    setError(null);
    setCompressing(true);
    try {
      setDraftBlob(await compressPhoto(file));
    } catch {
      setError("Impossible de lire cette photo. Essaie une autre image.");
    } finally {
      setCompressing(false);
    }
  }

  async function handleSave() {
    if (saving) return;
    setSaving(true);
    try {
      await onSave({
        ...entry,
        photo: draftBlob ? { id: crypto.randomUUID(), blob: draftBlob } : entry.photo,
        note: note.trim() || undefined,
        updatedAt: Date.now(),
      });
      setDraftBlob(null);
      setEditing(false);
    } catch {
      setError("Impossible d'enregistrer les modifications. Réessaie.");
    } finally {
      setSaving(false);
    }
  }

  const fileInput = (
    <input
      ref={fileInputRef}
      type="file"
      accept="image/*"
      capture="environment"
      className="visually-hidden"
      aria-hidden="true"
      tabIndex={-1}
      onChange={(e) => {
        const file = e.target.files?.[0];
        e.target.value = '';
        if (file) void handleFile(file);
      }}
    />
  );

  if (!editing) {
    return (
      <div className="detail" role="dialog" aria-label={`Détail du jour ${entry.dayNumber}`}>
        <div className="detail__bar">
          <button type="button" className="btn btn--icon" onClick={onClose} aria-label="Fermer">
            <X size={20} aria-hidden="true" />
          </button>
          <p className="detail__title">
            Jour {entry.dayNumber} — {entry.theme}
          </p>
          <button
            type="button"
            className="btn btn--icon"
            onClick={startEditing}
            aria-label="Modifier"
          >
            <Pencil size={20} aria-hidden="true" />
          </button>
        </div>
        {photoUrl && (
          <img className="detail__photo" src={photoUrl} alt={`Photo du thème « ${entry.theme} »`} />
        )}
        <p className="detail__date">
          Prise le{' '}
          {new Date(entry.takenAt).toLocaleDateString('fr-FR', {
            day: 'numeric',
            month: 'long',
            year: 'numeric',
          })}
        </p>
        {entry.note && <p className="detail__note">{entry.note}</p>}
        {fileInput}
      </div>
    );
  }

  return (
    <div className="detail" role="dialog" aria-label={`Modifier le jour ${entry.dayNumber}`}>
      <div className="detail__bar">
        <button type="button" className="btn btn--icon" onClick={cancelEditing} aria-label="Retour">
          <ArrowLeft size={20} aria-hidden="true" />
        </button>
        <p className="detail__title">
          Jour {entry.dayNumber} — {entry.theme}
        </p>
        <span className="detail__bar-spacer" />
      </div>
      {draftUrl ? (
        <img className="detail__photo" src={draftUrl} alt="Nouvelle photo" />
      ) : (
        photoUrl && (
          <img
            className="detail__photo detail__photo--current"
            src={photoUrl}
            alt="Photo actuelle"
          />
        )
      )}
      <button
        type="button"
        className="btn"
        onClick={() => fileInputRef.current?.click()}
        disabled={compressing}
      >
        <Camera size={18} aria-hidden="true" />
        {compressing ? 'Préparation…' : 'Remplacer la photo'}
      </button>
      <label className="field">
        Note (optionnel)
        <textarea
          className="field__input"
          rows={3}
          value={note}
          onChange={(e) => setNote(e.target.value)}
          placeholder="Un souvenir, un contexte…"
        />
      </label>
      {error && (
        <p className="detail__error" role="alert">
          {error}
        </p>
      )}
      <div className="detail__actions">
        <button type="button" className="btn" onClick={cancelEditing}>
          Annuler
        </button>
        <button type="button" className="btn btn--primary" onClick={handleSave} disabled={saving}>
          <Check size={18} aria-hidden="true" />
          {saving ? 'Enregistrement…' : 'Enregistrer'}
        </button>
      </div>
      {fileInput}
    </div>
  );
}

- [ ] **Step 5: Remplacer `src/App.tsx`**

```tsx
import { useCallback, useEffect, useState } from 'react';
import { CalendarDays, Camera, Images } from 'lucide-react';
import DayDetail from './components/DayDetail';
import GalleryView from './components/GalleryView';
import Toolbar from './components/Toolbar';
import TodayView from './components/TodayView';
import { listDays, nextDayNumber, replaceAllDays, saveDay } from './db';
import { buildExportFileName, exportDays, ImportError, parseImportFile } from './exportImport';
import { isChallengeComplete, loadThemes, ThemesError } from './themes';
import type { DayEntry } from './types';
import './AppShell.css';

type Tab = 'today' | 'gallery';

export default function App() {
  const [themes, setThemes] = useState<string[] | null>(null);
  const [themesError, setThemesError] = useState<string | null>(null);
  const [days, setDays] = useState<DayEntry[]>([]);
  const [tab, setTab] = useState<Tab>('today');
  const [selectedDayNumber, setSelectedDayNumber] = useState<number | null>(null);
  const [storageError, setStorageError] = useState(false);

  useEffect(() => {
    loadThemes()
      .then(setThemes)
      .catch((err) =>
        setThemesError(
          err instanceof ThemesError ? err.message : 'Erreur inconnue au chargement des thèmes.',
        ),
      );
  }, []);

  const refreshDays = useCallback(async () => {
    try {
      setDays(await listDays());
    } catch {
      setStorageError(true);
    }
  }, []);

  useEffect(() => {
    void refreshDays();
  }, [refreshDays]);

  const completedDays = days.length;
  const challengeComplete = themes !== null && isChallengeComplete(completedDays, themes.length);
  const currentDayNumber = nextDayNumber(days);
  const currentTheme = themes !== null && !challengeComplete ? themes[completedDays] : '';
  const selectedDay = days.find((day) => day.dayNumber === selectedDayNumber) ?? null;

  async function handleComplete(photo: Blob, note: string | undefined) {
    if (themes === null || challengeComplete) {
      throw new Error('le défi est terminé');
    }
    const entry: DayEntry = {
      dayNumber: currentDayNumber,
      theme: currentTheme,
      photo: { id: crypto.randomUUID(), blob: photo },
      note,
      takenAt: Date.now(),
      updatedAt: Date.now(),
    };
    await saveDay(entry);
    await refreshDays();
  }

  async function handleSaveDay(entry: DayEntry) {
    await saveDay(entry);
    await refreshDays();
  }

  async function handleExport() {
    const json = await exportDays(days);
    const url = URL.createObjectURL(new Blob([json], { type: 'application/json' }));
    const a = document.createElement('a');
    a.href = url;
    a.download = buildExportFileName();
    a.click();
    URL.revokeObjectURL(url);
  }

  async function handleImport(file: File) {
    try {
      const imported = parseImportFile(await file.text());
      const ok = window.confirm(
        `Remplacer les ${days.length} entrées actuelles par les ${imported.length} entrées du fichier ?`,
      );
      if (!ok) return;
      await replaceAllDays(imported);
      await refreshDays();
      setSelectedDayNumber(null);
    } catch (err) {
      window.alert(
        err instanceof ImportError
          ? `Import échoué : ${err.message}`
          : 'Import échoué : fichier illisible.',
      );
    }
  }

  if (themesError) {
    return (
      <div className="app">
        <div className="error-screen">
          <h1>365 Calendar</h1>
          <h2>Impossible de charger les thèmes</h2>
          <p>{themesError}</p>
          <p>
            Le fichier <code>public/themes.json</code> doit contenir un tableau JSON de thèmes non
            vides : <code>["Rouge", "Eau", …]</code>
          </p>
        </div>
      </div>
    );
  }

  if (themes === null) {
    return (
      <div className="app">
        <p className="loading">Chargement…</p>
      </div>
    );
  }

  return (
    <div className="app">
      <header className="app-header">
        <div className="app-brand">
          <CalendarDays size={26} aria-hidden="true" />
          <h1 className="app-title">365 Calendar</h1>
        </div>
        <Toolbar onExport={handleExport} onImport={handleImport} />
      </header>
      {storageError && (
        <p className="storage-banner" role="alert">
          Stockage indisponible : impossible d'enregistrer tes photos dans ce navigateur (mode
          privé ?).
        </p>
      )}
      <main className="app-main">
        {tab === 'today' ? (
          <TodayView
            dayNumber={currentDayNumber}
            theme={currentTheme}
            completedDays={completedDays}
            themeCount={themes.length}
            challengeComplete={challengeComplete}
            onSave={handleComplete}
            onEditLast={() => {
              if (days[0]) setSelectedDayNumber(days[0].dayNumber);
            }}
          />
        ) : (
          <GalleryView days={days} onSelect={setSelectedDayNumber} />
        )}
      </main>
      <nav className="tabbar" aria-label="Navigation principale">
        <button
          type="button"
          className={`tabbar__seg${tab === 'today' ? ' active' : ''}`}
          aria-pressed={tab === 'today'}
          onClick={() => setTab('today')}
        >
          <Camera size={18} aria-hidden="true" /> Aujourd'hui
        </button>
        <button
          type="button"
          className={`tabbar__seg${tab === 'gallery' ? ' active' : ''}`}
          aria-pressed={tab === 'gallery'}
          onClick={() => setTab('gallery')}
        >
          <Images size={18} aria-hidden="true" /> Galerie
          <span className="tabbar__count">{days.length}</span>
        </button>
      </nav>
      {selectedDay && (
        <DayDetail
          entry={selectedDay}
          onClose={() => setSelectedDayNumber(null)}
          onSave={handleSaveDay}
        />
      )}
    </div>
  );
}
```

Note : `themes[completedDays]` est le thème courant (0-indexé) — le thème est figé dans l'entrée au moment de la validation (spec). `days` est trié décroissant par `listDays`, donc `days[0]` est la dernière entrée (utilisée par « Modifier » du panneau de succès).

## Récapitulatif des règles métier (rappel pour l'exécutant)

1. Le thème courant est `themes[completedDays]` (0-indexé) ; `completedDays` = nombre d'entrées.
2. Le `dayNumber` attribué à la validation = `nextDayNumber(days)` = max existant + 1 (jamais de renumérotation).
3. Le thème est figé dans l'entrée au moment de la validation.
4. Le brouillon (photo sélectionnée + note) vit en mémoire de session uniquement ; l'entrée n'est créée qu'à la validation.
5. Une seule photo par jour ; remplacer = nouvel id + nouveau blob.
6. Import = remplacement complet après validation stricte et confirmation ; transaction atomique.
7. Interface en français, données en IndexedDB `calendar365` (store `days`), jamais envoyées.
